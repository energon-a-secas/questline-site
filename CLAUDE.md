# CLAUDE.md: Questline

Questline: onboarding hub as a NieR-style game console: Brief, Chapters (big cards → navigable section-reader modal, generic engineering field-manual content), Playbooks (editable workflows), Priority, Intel (basic/company/operating glossary), Sites (curated tools), Atlas (team topology), Profile (engineer classes + certification ladders), Flow, System; global command-palette search (/ or rail button) across every section/term/class, gacha event banners with live countdowns, quick menu, keyboard nav; dual theme (Night console dark / Day clinical light) driven by css/parts/tokens.css, media plates stay dark via plate-local --banner-* tokens; library.html is the component-library showcase (tokens + every variant, copyable markup) (questline.neorgon.com)

**Live:** questline.neorgon.com · **Port:** 8832

## Run

```bash
make serve
```

Then open http://localhost:8832. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/data.js`, `js/events.js`, `js/library.js`, `js/console.js`, `js/state.js` are already past it. Split when touching them, do not grow them further.
