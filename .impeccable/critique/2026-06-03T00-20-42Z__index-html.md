## Anti-Patterns Verdict

**Not AI slop.** The CSS carries explicit anti-slop decisions (the cyan "notch" rejecting a full-height side-stripe at style.css:973; one unified `--accent` collapsing two near-identical blues at :687; the "cursor is an outline ring, never a fill" rule at :1238). No gradient text, no hero-metric template, no identical card grid, no modal-as-first-thought. Reads as authored and reference-driven (NieR + Detroit), self-aware.

**Category-reflex caveat:** "make a corporate doc feel like a game" → dark UI + cyan glow + angular HUD is the single most-guessable execution of that brief. The craft redeems it, but the aesthetic family is guessable from category-plus-anti-references.

**Deterministic scan (Puppeteer, live URL):** 22 findings. ~17 are repeated `ai-color-palette` (cyan-on-dark) — the deliberate NieR theme, design-intent not slop. Genuinely actionable: `low-contrast` white #fff on azure #2aa8ff = 2.6:1 (primary CTA, fails AA); `low-contrast` header title on gradient (median 3.2:1); `bounce-easing` cubic-bezier(0.34,1.56,0.64,1) on logo hover + quick menu (violates no-overshoot law); `layout-transition` animating `width` on the XP bar. CLI static scan (index.html only) added `single-font` + `flat-type-hierarchy` — partial false positives (styles are external; single font is acceptable in product register).

## Priority Issues

**[P1] White text on the azure primary button fails WCAG AA.** `.btn--primary` is #fff on #2aa8ff = 2.58:1 (style.css:272), same for `.auth-submit` (:413). Both assessments independently flagged it. It's the most important CTA ("Open chapters") and the one genuinely inaccessible element in an otherwise high-contrast UI. Fix: use dark ink (#06121f, already used on active tabs/rows) on the azure fill, which passes easily.

**[P1] The "Intel unlocked" reward is theatre — intel is never actually locked.** All 8 Intel terms are always visible regardless of progress, yet clearing a chapter fires an "Intel unlocked" codex toast (celebrate.js:67, events.js:189). The headline game-feel promise is hollow. Fix: either gate Intel rows behind their `chapter` field (data already present in data.js:238) so they genuinely unlock, or change the copy to "Field notes added" so it stops claiming an unlock that didn't happen.

**[P2] The keyboard/console model is powerful but untaught.** hold-Enter-to-complete (keynav.js:145), Q/E tab cycling, hold-Esc radial menu are only terse glyphs on the bottom bar; no first-run hint; the radial reaches only 4 of 6 tabs. The app's main differentiator is invisible to mouse-only users. Fix: dismissible first-run coach-mark gated by a localStorage flag; reconsider hold-Enter (a discoverable "Finish" button already exists, making the hold gesture redundant risk).

**[P2] Reset is an irreversible cliff with no recovery.** onReset (events.js:198) wipes all progress, copy says "It cannot be undone." Only real anxiety valley in an otherwise generous emotional design. Fix: undo toast holding the wiped `done` object ~8s, or export-before-reset.

**[P2] Header title contrast on the gradient.** Detector-only: "Questline" + subtitle render at median 3.2:1 / 1.2:1 worst-pixel over the purple-navy header gradient (style.css:175 endpoint #040714 is pre-rebrand). Fix: darken the gradient or add a subtle text shadow/scrim under the title.

## Persona Red Flags

**Alex (Power User):** Keyboard nav is excellent and deep — Alex is the winner here. One snag: hold-Enter can complete a whole chapter accidentally while skimming with arrows; and the radial quick menu only jumps to 4 of 6 tabs, so Intel/System need a different path.

**Jordan (First-Timer):** No onboarding. Lands on Brief, sees a CTA (good), but the entire keyboard apparatus and the hold-Esc menu are undiscoverable; the "Intel unlocked" toast promises a codex that's already fully open when they look. Mouse-only Jordan may never learn Q/E or the quick menu exists.

**Sam (Low-vision / a11y):** The primary CTA label fails AA (2.6:1) and the header title dips to ~3.2:1 on the gradient. Everything else (body text, tags, done-green) passes AA/AAA comfortably, so these two are isolated and cheap to fix.

## Minor Observations

- Recursive self-gloss: "spec" inside the Spec Intel entry tooltips itself (glossary.js:30 scans `.cintel__body`); exclude the open term.
- `theme-color` meta (#040714, index.html:19) and the header gradient endpoint reference the pre-rebrand bg, not the live `--bg` #0a1424.
- Rank blurb can go stale: "Recruit — start at Foundations" showed while Foundations was already cleared (data.js:36). Make the lowest-rank blurb progress-aware.
- `bounce-easing` + `transition: width`: the spring logo hover and XP-bar width animation violate the no-overshoot / no-layout-animation laws. Low-stakes but real; swap to ease-out-expo and animate transform/scaleX.
- og:image points to og-preview.jpg while the project uses .png elsewhere; verify the asset exists.
