# Questline — Launch Polish: Shape System + Flagged-Area Fixes

> Generated by neorgon-forge swarm (UX · Design · Engineering · QA) on 2026-06-16

## Summary

After the first polish pass the owner reports the site "hasn't improved that much" and still
lacks the polish of a Fortune-500 game UI. The swarm's root-cause finding: **four competing
shape vocabularies fight on every screen** with no rule for which shape means what. Faceted
plates, rounded cards, and pills are mixed arbitrarily across surfaces that share the same
semantic role, and ~20 hand-written `clip-path: polygon()` literals use six different bevel
sizes (4/5/6/8/10/14px), none derived from `--bevel`. That inconsistency — not a lack of
effects — is what reads as "unfinished."

This plan establishes **one shape system** and applies it, fixes the five flagged areas
(Daily dispatch void, Flow D-pad removal, Atlas topology spaghetti, invisible pagination dots,
dedicated class-select screen), and consolidates tokens. Static zero-build ES-module app; no
new dependencies.

## Problem Statement

1. No coherent shape/model language — plates, cards, and buttons don't visually agree.
2. Inconsistent gaps between boxes and uneven grid column widths.
3. Daily dispatch ("Operator's Log / Upcoming events"): large empty void above the card,
   redundant triple-header, oversized rotated background glyph.
4. Flow "Map navigation" D-pad floats over and overlaps the node map — out of place.
5. Atlas topology: tangled diagonal SVG wires that don't even connect their endpoint cards.
6. Banner/daily pagination dots: inactive dots invisible, so users don't know more items exist.
7. "Choose up to two classes" picker is a flat inline list, not an interactive, resettable,
   dedicated experience.

## Scope

### In Scope
- A single documented shape system (plates faceted · controls rounded · pills round · glyphs soft-square) and a bevel/radius/gap token scale.
- Daily dispatch layout fix (CSS-led, optional markup trim).
- Flow D-pad **removal** (owner decision) + keyboard/touch nav preserved + hint copy fix.
- Atlas topology edges → **hover/focus-on-demand**, plus accessible text link list.
- Pagination dots → visible segmented track + count, unified across banner & daily.
- Dedicated **class-select screen** (select up to 2 → Confirm → sheet; Change classes; System reset).
- Token consolidation + service-worker cache bump.

### Out of Scope
- Content/data changes to chapters, intel, playbooks.
- New backend or persistence schema (keep `s.profile.classIds` as-is).
- Pixel-accurate orthogonal SVG routing for Atlas (deferred; hover-only chosen instead).
- Banner "N / M" count label is optional (nice-to-have).

## Owner Decisions (locked)

- **Class picker** → dedicated class-select screen with Confirm + Change + System reset.
- **Flow D-pad** → removed entirely (keyboard arrows + click/tap nodes + hint bar).
- **Workflow** → plan first (this doc), approve, then build.

## UX Design

### User flows

**Class selection** (primary new flow):
1. Enter Profile with no class → **Select screen** (4 crest plates, "Pick up to two").
2. Toggle up to 2 (3rd blocked with announced feedback); live "N / 2 selected" count.
3. **Confirm** (disabled until ≥1) → transition to the **class sheet** (certification ladder).
4. **Change classes** (in sheet head) → back to select with prior picks pre-checked.
5. **System → Reset class & certifications** → clears choices → next Profile visit = Select.

**Flow navigation** (after D-pad removal):
- Mouse/touch: tap a node (each is an `<a href="#flow/<id>">`) → focus map.
- Keyboard: arrow keys move the cursor ring, Enter focuses (unchanged `keynav.js` logic).
- Orientation: rank panel lead + fog footnote + a one-line "tap a chapter" caption for touch.

### Key states
- **Daily dispatch:** default (≥2 events, centered card, "i of n" caption + dots), single event (no dots, no auto-rotate), dismiss-to-empty (auto-close).
- **Class select:** empty/selecting (counter + Confirm), confirmed (sheet + Change), ladders-hidden (existing System pref path), reset.
- **Atlas:** default (clean lanes, legend, no global wires), hover/focus/tap a team (its edges + dim others + text link list), empty lane.
- **Dots:** idle (visible ~3:1), active (accent + glow), focus-visible (ring), single item (hidden).

### Interaction details
- Confirm is the single primary action on the select view; disabled state uses `disabled` + visible hint, not color alone.
- 3rd-class block: keep selection, show announced toast "You can pick up to two classes. Deselect one first."
- Daily: set initial focus to the active card on open; status caption is **not** in a live region (would double-announce on rotate).

### Accessibility
- Flow: remove the only `aria-label="Map navigation"` with the pad; ensure one node stays keyboard-reachable; node cards ≥44px touch targets.
- Class cards: `<button aria-pressed>` grouped in a labeled region; live "N/2" count; move focus to sheet heading on Confirm, back to picker on Change.
- Daily: keep focus trap + Esc + focus-return; **add initial focus** (currently missing vs `modal.js`).
- Atlas: SVG is `aria-hidden`, so per-card text link list (`X-as-a-Service → Payments Platform`) is required, not optional; pair hover with `focusin`/`focusout` + tap; mode distinguished by dash pattern, not color alone.
- Dots: idle ≥3:1 (WCAG 1.4.11), `:focus-visible` ring, daily dots padded to ≥44px hit area.

## Technical Design

### Architecture fit
- Views return HTML strings via `shell()` (`js/console.js:124`); `render()` full write, `rerenderActive()` in-place (`js/render.js:91`).
- Transient UI state lives in `state.ui` (never persisted); persisted slots have their own localStorage keys. New mode flag follows the existing `credEditing`/`playbookEdit` pattern.
- Delegated click handling in `js/events.js`; Profile clicks via `handleProfileClick`.
- Tokens: global scale in `css/parts/base.css :root`; plate/elevation tokens in `css/parts/flow.css :root`.

### The shape system (the core fix)

> **Plates are faceted. Controls are rounded. Pills/tags are fully round. Status glyphs are soft-square. Nothing else cuts corners.**

Add a bevel scale to `base.css :root` (drop base `--bevel` 12px → 10px so panels match cards):
```
--bevel-lg: 14px;  /* hero plates: banner, daily, rankup, command palette, modal */
--bevel:    10px;  /* standard plates: cpanel, cchapter, cband, crung, ccert, catlas card, tnode */
--bevel-sm: 6px;   /* small faceted controls only where faceting is intentional (qm wedge) */
--card-min: 240px; /* one grid floor for cchapters / cclasses / csite-grid */
```

| Tier | Shape | Members |
|------|-------|---------|
| **Plate** (faceted, TL+BR, `--plate-poly` via `.fbevel`) | `clip-path` | `.cpanel`, `.cchapter` (done) → **convert:** `.tnode__inner`, `.cband`, `.crung`, `.ccert`, `.cclass`, `.skill`, `.catlas__card` (retoken) |
| **Control** (rounded `--radius-sm` 6px) | `border-radius` | `.btn*` (law), **de-facet:** `.cdone`, `.cseal`, toggles, `.creader__*` buttons, search inputs, `.flowpad__*` (being removed) |
| **Pill** (round 999px) | `border-radius` | `.skill__tag`, `.ctag`, `.cscope`, `.cplaybook__tag`, `.daily__timer`, `.banner__timer` |
| **Status glyph** (soft-square 6px) | `border-radius` | `.skill__check`, `.cshiftbox__check`, `.ccert__status-glyph`, `.cdone__box`, `.tnode__seal` |

The diagonal accent tick (`.cpanel::after` / `.cchapter::after`) becomes the one repeated
state-accent motif across all plates (extract to a shared selector).

**Gap scale:** `--space-4` (16px) for plate-to-plate grids (`.cchapters`, `.cbands`,
`.catlas__lanes`, `.cbrief`, `.cclasses` ← bump from `--space-3`); `--space-3` (12px) for items
inside a plate (`.catlas__lane-items`, `.skills`, `.cladder-rungs`, `.ccerts`). Unify grid
floors to `--card-min`. Replace the magic `52px` tree-row gap with `--space-8`.

## Implementation Plan

### Phase 1 — Removals & isolated CSS (no state risk)
- Remove Flow D-pad (markup, dead handlers `onFlowMove`/`onFlowActivate`, CSS) — verify `keynav.js` arrow nav intact; fix hint copy at `flow.js:135`.
- Daily dispatch layout (stage height, card centering, glyph, header de-dup, initial focus).
- Atlas edges → hover/focus-only + per-card text link list + legend promotion.

- **Deliverable:** flagged visual bugs gone; keyboard + touch nav verified.

### Phase 2 — Class-select state machine
- `state.js` add `ui.classSelecting`; `profile.js` mode branch (select vs confirmed); `events.js`
  add `data-class-confirm` / `data-class-change` / `data-class-cancel` + clear flag on reset;
  reuse System `#resetClassBtn`. Faceted crest plates + confirm bar in `profile.css`.
- **Deliverable:** select→confirm→sheet→change→reset round-trip; legacy `classId` migration intact; reload lands on sheet when classIds non-empty.

### Phase 3 — Shape system rollout
- Add bevel/gap tokens; convert plates; de-facet controls; round pills; standardize glyphs and gaps; unify grid floors.
- **Deliverable:** one consistent shape language across every tab.

### Phase 4 — Consolidation + cache bump + regression sweep
- Move `--radius-md` to base; retoken Atlas hardcoded polygons; reserve accent glow for active/done/primary-CTA only; drop stacked decorative gradient washes.
- Bump `sw.js` `CACHE_NAME` v5→v6; full visual sweep of every clip-path surface; hard-reload twice.
